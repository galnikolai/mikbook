# Периметр MIKBOOK: MVP vs полный ТЗ

## Решение

Стартуем с **Фазы 1 (MVP)**. Полный ТЗ (AI-перевод, AI-игры, баттлы, тариф «по главе», нативные приложения) — следующие фазы после валидации оплаты и retention.

## Входит в MVP (Фаза 1)

| Блок | Scope |
|------|--------|
| Лендинг | Editorial-коллаж по атмосфере Readymag (упрощённая сетка) |
| Auth | Email / magic link (Auth.js) |
| Подписки | Stripe Billing: `monthly`, `yearly` |
| Reader | HTML-развороты, TOC слева, 1–3 демо-разворота на главу |
| Заметки | Личное текстовое поле под разворотом |
| Защита v1 | Watermark userId, лимит одновременных сессий |
| Админка | Базовый CMS контента глав/разворотов |
| i18n | Только FR на старте |

## Бюджетный коридор

| Этап | Бюджет (ориентир) |
|------|-------------------|
| MVP Фаза 1 | **45 000 – 70 000 €** |
| Резерв Фазы 2–3 | 40 000 – 90 000 € |
| Только лендинг (атмосфера) | ~1 000 – 3 500 € |

Ставки: Восточная Европа / смешанная EU (~40–80 €/ч). Французское агентство ×1.5–2.5.

## Вне MVP (позже)

- Тариф `per_chapter`
- AI-квизы / флеш-карты / клинические случаи
- AI-перевод на европейские языки
- Баттлы, аватары, видео операций
- Жёсткий DRM / native iOS/Android
- Pixel-perfect коллаж всех ~38 кадров Readymag

## Масштаб

Цель: 3 000–5 000 студентов/год. Старт: 1 регион (Vercel/Railway + managed Postgres). «2 сервера» — при росте (app + workers / replica).
